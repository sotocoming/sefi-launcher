# Discord: статус Sweet Home

В профиле Discord отображаются название приложения Sweet Home, актуальный значок приложения Discord, текущий режим игры и время с запуска Minecraft. Sweet Home указан только в заголовке приложения. Ниже отображаются «На сервере · N игроков» и текущий мир с EURO / RU из конфигурации SEFI. Для других серверов адреса не публикуются.

## Настройка приложения

1. В Discord Developer Portal создать отдельное приложение `Sweet Home`.
2. В General Information выбрать нужный App Icon и сохранить изменения. Art Assets для картинки статуса не требуются.
3. Публичный Application ID записать в `electron/discord-presence-config.json`, поле `applicationId`, и пересобрать лаунчер.

Bot Token, Client Secret, OAuth, приглашение бота на сервер и права аккаунта для Rich Presence не используются. С пустым ID подключение к Discord выключено.

На компьютере игрока должен работать Discord Desktop. Отображение игровой активности должно быть разрешено в его настройках. Переключатель «Показывать игру в Discord» в настройках SEFI выключает соединение и очищает статус сразу.

## Состояния

- Лаунчер, подготовка и запуск игры.
- В главном меню Minecraft.
- На сервере · N игроков — после появления игрового мира на одном из известных адресов сервера. Онлайн берётся из списка игроков, доступного клиенту.
- Обычный мир, Незер или Энд — из фактического ключа измерения, без координат. Для нестандартных измерений — «Другой мир».
- EURO / RU — метка фактического адреса подключения, а не выбранное до запуска значение.
- Одиночный мир.
- Другой сервер — без адреса, ника и названия частного мира.
- Minecraft запущен — если heartbeat устарел или недоступен.

Клиентский мод SEFI Skins 1.3.0 раз в четыре секунды пишет маленький JSON в отдельную временную папку запуска. Данные снимаются в клиентском потоке, запись выполняется в фоне. Лаунчер читает не более 2048 байт; heartbeat старше 15 секунд отбрасывается. Игровые пароли и сессии не используются. Discord получает данные только через свой локальный IPC; обновления объединяются с интервалом 15 секунд. При перезапуске Discord соединение восстанавливается. Отсутствие Discord и ошибки статуса не блокируют игру.

Серверные моды и API не меняются. Для проверки в Minecraft нужен обновлённый клиент. Старый JAR переносится в резервную папку при установке нового.

## Проверки

```
npm run build
npx tsc --noEmit
node scripts/test-discord-presence.cjs
node scripts/test-discord-presence-ui.cjs
node scripts/test-window-loading.cjs
node scripts/test-game-lifecycle.cjs
node scripts/test-skin-mod.cjs
```

В `skin_build` выполнить Gradle build на JDK 17+ и включить remapped JAR в resources/mods. До публикации проверить статус в настоящем Discord: меню, подключение к обоим адресам Sweet Home, отключение, одиночный мир, таймер, выключение переключателя и повторный запуск Discord. Сообщения Discord о задержке загрузки art assets не означают ошибку клиента.

Иконка берётся из публичных метаданных приложения Discord при включении статуса и проверяется раз в минуту. После смены App Icon лаунчер получит новый хеш изображения и отправит новый URL в Rich Presence без перезапуска и нового релиза. Учётные данные Discord не нужны. При ошибке сети сохраняется последняя успешно полученная иконка; если такой ещё нет, устаревшая картинка не подставляется. После удаления App Icon отдельная картинка статуса тоже очищается.
