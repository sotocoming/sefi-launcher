# SEFI Launcher

Лаунчер Minecraft Java для сообщества SEFI и сервера Homestead Cozy.

## Возможности

- Вход в SEFI Community через сайт в системном браузере.
- Вход Microsoft и подтверждённая привязка Minecraft Java к профилю сообщества.
- Автоматический вход стандартного профиля SEFI с проверкой конкретного игрового подключения.
- Установка сборки, новости, карта и состояние сервера.
- «Играть» по умолчанию открывает меню Minecraft. Для быстрого подключения включите
  «Подключаться сразу» в карточке сервера и выберите EURO / RU; лаунчер запоминает этот выбор.
  Адреса приходят из `/api/launcher/config` (`server.endpoints`) и также отображаются
  в карточке сервера для копирования. Если выбранный адрес удалён, выберите другой
  или отключите быстрое подключение.
- Реакции на новости для авторизованных пользователей сообщества.

Готовый установщик Windows: [последний релиз](https://github.com/sotocoming/sefi-launcher/releases/latest).
Установщик пока не подписан цифровой подписью.

## Code signing policy

Готовим подключение SignPath Foundation; действующие релизы пока не следует считать подписанными.
[Правила подписи](CODE_SIGNING.md) · [Политика конфиденциальности лаунчера](PRIVACY.ru.md) ([English](PRIVACY.md)) · [Лицензия MIT](LICENSE).

Лицензия проекта распространяется на собственный код SEFI. Сторонние зависимости,
игра, Java, моды и материалы сохраняют свои лицензии и уведомления; MIT проекта их не заменяет.

## Политика в установщике

При обычной установке перед записью файлов показывается политика конфиденциальности.
На Windows с русским языком установщик и текст политики — на русском; для остальных
языков используется английский вариант. Можно прочитать документ и отменить установку.
Это информационная страница: она не меняет настройки передачи данных.
При тихом обновлении служебные страницы пропускаются стандартным механизмом NSIS.
Копии политик, лицензии и правил подписи также сохраняются в resources/docs установленного приложения.

Тексты установщика формируются из PRIVACY.md и PRIVACY.ru.md перед упаковкой.
Проверка их актуальности: node scripts/installer-privacy.cjs --check.

## Установка и восстановление сборки

Лаунчер сохраняет оригинальные имена файлов CurseForge. Моды устанавливаются в `mods`,
ресурс-паки — в `resourcepacks`, шейдеры — в `shaderpacks`. Загрузки проверяются на
целостность ZIP/JAR и записываются через временные файлы. Для повторной проверки
сохраняются размеры и SHA256; уже проверенные загрузки используются из локального кэша.
Если в конфигурации задан SHA256 архива сборки, он также проверяется перед установкой.
Локальные контрольные суммы и CRC не являются антивирусной проверкой или подписью автора.

Неполная установка не считается готовой и блокирует запуск. При обновлении со старого
лаунчера выполняется автоматическая проверка и восстановление; файлы `mod-ID-ID.jar`
переносятся из `mods` в `sefi-backups`. Пользовательские моды с другими именами остаются,
а существующие `options.txt` и список серверов сохраняются.

Настройка «Скрывать лаунчер на время игры» скрывает окно после запуска Minecraft и
возвращает его после выхода. Процесс лаунчера остаётся работать для автовхода SEFI.

## Русский перевод Homestead Cozy 1.3.7

В комплект 1.1.0 включён проверенный перевод SEFI: ресурс-пак, клиентский мод,
книги, задания, подписи меню и скриптов. Исходные сторонние JAR и стандартный
шрифт Minecraft не заменяются. Исходник перевода: `codex/mods-ru`, коммит
`bc210ef6e6b7f4fa937b66104de3ac56bb8036bc` серверного репозитория.

Перед каждым запуском, после установки или восстановления основной сборки,
лаунчер проверяет SHA256 пакета и 63 файлов перевода. Перевод привязан к
проверенному архиву Homestead: для другой версии нужен совместимый лаунчер.
Неизвестные изменения в заменяемых файлах останавливают установку с указанием
пути. Перед заменой создаётся `sefi-backups/localization/launcher-*/manifest.json`
с оригиналами. При ошибке записи заменённые файлы восстанавливаются.

При первом применении включаются русский язык и ресурс-пак SEFI; остальные
параметры options.txt и пользовательские ресурс-паки сохраняются. После этого
выбор языка и включённых паков остаётся за игроком. Миры, аккаунты и прогресс
не входят в пакет. Проверка: `node scripts/test-localization.cjs`.

## Java клиента

По умолчанию SEFI использует собственную 64-битную Temurin Java 21 для Homestead / Minecraft 1.20.1.
При первом запуске архив JRE скачивается из официального API Adoptium и GitHub-релиза Temurin.
Java хранится в `userData/runtimes/java-21-win32-x64`, без установки в Windows, прав администратора
и изменения PATH/JAVA_HOME. Автоустановка пока доступна для Windows x64.

Перед распаковкой проверяются размер, SHA256 и безопасные пути архива. Установка завершается
только после пробного запуска. Повреждённая Java восстанавливается при следующем запуске;
проверенная копия используется без интернета. Обновление уже исправной Java до нового патча
пока не выполняется автоматически.

В настройках отображается реальный результат проверки, доступна кнопка «Скачать Java SEFI».
Ручной выбор Java сохранён: проверяются Java 21 и 64-битная архитектура. Перед запуском игры
в обоих режимах проверяется запуск JVM с выбранным объёмом памяти. Кнопка «Java SEFI»
возвращает автоматический режим. Для других ОС можно выбрать свою Java 21.

Проверка установки, повреждения, восстановления, одновременных запросов и работы без сети:

```sh
node scripts/test-managed-java.cjs
```

## Папка игры

Если в настройках выбран корень диска (например, D:\), SEFI использует отдельную папку
D:\SEFI Minecraft. Это правило применяется и к ранее сохранённым настройкам.
Перед загрузкой игры лаунчер создаёт папку и проверяет возможность записи.
Отказ доступа, недоступный диск и нехватка места показываются с путём и советом выбрать другую папку.

Проверка путей: `node scripts/test-game-directory.cjs`.

## Разработка

Требуется Node.js 20 и npm. Из корня репозитория:

```sh
npm ci
npm run dev
```

Проверка и сборка приложения:

```sh
npm run build
npm run package -- --publish never
```

Windows CI запускается вручную во вкладке Actions и сохраняет установщик как артефакт.
Проверенные релизы публикуются отдельно, чтобы CI не создавал повторные черновики.

## Мод авторизации

Исходники Fabric 1.20.1 находятся в `mod_build`, готовый клиентский мод — в `resources/mods`.
Для пересборки мода нужны Java 17 и Gradle 8.12.1:

```sh
cd mod_build
gradle build
```

Лаунчер и клиентский мод не содержат серверных ключей. Развёртывание собственного сервера
требует отдельного бэкенда, EasyAuth и закрытой серверной конфигурации; одного клиентского
мода для автовхода недостаточно. Обычные сторонние лаунчеры поддерживаются сервером через
персональный игровой пароль либо подтверждённую Microsoft-сессию.

## Скины SEFI

В «Аккаунтах» появился блок внешнего вида активного профиля: выбор PNG 64×64 или 128×128 (до 128 КБ),
3D-предпросмотр с вращением мышью или стрелками, масштабирование колесом, возврат
ракурса, обычная/тонкая модель, сохранение, отмена и сброс. Голова в боковой карточке
загружается из сохранённого скина вместе со вторым слоем и обновляется автоматически.
Общие скины доступны стандартным профилям SEFI Community. Для Microsoft и профилей
с привязанной лицензией показывается ссылка на официальный кабинет Minecraft.

Клиентский Fabric-мод `resources/mods/sefi-skins-1.3.0.jar` устанавливается для обоих
типов аккаунтов. Он асинхронно получает скины по offline UUID + серверному нику,
обновляет их раз в 45 секунд и отдаёт приоритет официальным UUID/текстурам.
Сервер повторно проверяет владельца, лицензию и доступ при каждой выдаче.

Подготовленный серверный патч и инструкция: [server_skin_patch](server_skin_patch/README.md).
Серверный патч развёрнут 2026-10-08; обновлённый лаунчер ещё не опубликован.
При недоступности API лаунчер объясняет недоступность сохранения,
а игра продолжает использовать обычные и официальные скины. Общая видимость требует
обновлённого лаунчера у всех участников.

Исходники мода: `skin_build` (Java 17+, Gradle 8.12.1). `gradle build` включает
проверку защиты Microsoft UUID и официальных текстур.

Дополнительные локальные проверки:

```sh
npx tsc --noEmit
node scripts/test-skins.cjs
node scripts/test-skin-mod.cjs
node scripts/test-skins-ui.cjs
node scripts/test-skins-packaged.cjs
```

Последняя проверка интерфейса использует Playwright из локального Codex runtime и
установленный Edge; её пути можно изменить под свою среду. Проверки API в панели:
`python panel/deploy/test_community_skins.py`.

## Статус в Discord

Лаунчер показывает Sweet Home с актуальным значком приложения Discord, временем игры и реальным состоянием Minecraft: меню, одиночный мир или сервер. Статус можно отключить в настройках. Для работы нужен Discord Desktop и Application ID; настройка и проверки описаны в [docs/discord-presence.md](docs/discord-presence.md).
## Исправление Shift/Ctrl + ЛКМ

В «Настройки → Управление в Minecraft» есть кнопка «Исправить Shift/Ctrl + ЛКМ». Она отключает пять конфликтующих назначений JEI на левую кнопку мыши, сохраняет остальные настройки и назначения на другие клавиши. Отсутствующие записи добавляются как отключённые, чтобы не включились конфликтующие значения по умолчанию.

Minecraft должен быть закрыт. Лаунчер проверяет свой статус и запущенные процессы Minecraft, сохраняет исходный options.txt в sefi-backups/controls, проверяет отсутствие параллельных изменений и атомарно заменяет файл. Повторное исправление не создаёт новые копии. Для текущих версий доступен scripts/repair-click-bindings.ps1; параметр -GameDirectory задаёт папку вручную, по умолчанию читается settings.json лаунчера.

Проверки: node scripts/test-control-repair.cjs; powershell -NoProfile -File scripts/test-control-repair.ps1; node scripts/test-control-repair-ui.cjs. Проверка интерфейса использует изолированный Edge и Playwright из Codex runtime; это тестовые зависимости, не зависимости установленного лаунчера.

## Отчёты из Minecraft

Команда /report открывает короткую форму: тема, описание и необязательные шаги. Выбор приложений и предпросмотр находятся отдельно. По умолчанию выбраны версии модов, их контрольные суммы, ресурс-паки, настройки, ошибки без чата и существующая запись кнопок. Любое приложение можно исключить. Запись кнопок выключена при запуске, включается вручную на срок до двух минут и не фиксирует текст ввода; без записи пустое вложение не отправляется.

Мод sefi-input-diagnostics-0.2.0.jar устанавливается из ресурсов лаунчера. Предыдущая версия нашего диагностического мода переносится в резервную папку. Токен Community остаётся в лаунчере: мод отправляет выбранные данные через локальный сервис, проверяющий разовый ключ этого запуска, Origin, Host и объём данных.

Перед отправкой сохраняется локальная копия в sefi-reports. Для живой доставки нужна серверная часть /api/public/community/client-report. Отчёты хранятся отдельно и доступны только администраторам панели. Создание тикета Discord выбрано по умолчанию, его можно отключить перед отправкой. При привязанном Discord создаётся обычный тикет с доступом автора; без привязки — служебный тикет только для команды, с ником Minecraft и номером профиля SEFI. Для других лаунчеров доступно сохранение копии.

Исходники мода: reports_build (Java 17+, Gradle 8.12.1). Проверки: node scripts/test-report-broker.cjs; сборка Gradle; существующие проверки запуска и UI восстановления. Серверный пакет сопровождается отдельным манифестом сверки с работающими файлами. Не публиковать клиент раньше включения серверного приёма и проверки пользовательской отправки.


## Исправление крашей карты

Перед каждым запуском лаунчер устанавливает клиентский мод `sefi-claims-color-fix-1.0.1.jar` для Xaero World Map 1.40.16 и Open Parties and Claims 0.26.2. Если сведения о цвете привата ещё не получены, карта использует основной цвет владельца или временно серый. Серверные приваты, UUID и права доступа не изменяются. Предыдущие версии этого исправления переносятся в `sefi-backups/claims-fix-*`. Для ручной установки достаточно скопировать JAR из `resources/mods` в папку игры `mods` при закрытом Minecraft.

Версия 1.0.31 исправляет ошибку размещения вспомогательного класса в Mixin-пакете из выпуска 1.0.30. Перед сборкой add-on обязателен изолированный прогон настоящего Fabric/Mixin.


## Добровольный отчёт о сбое

После ошибки запуска доступна кнопка «Отправить отчёт»; ту же форму можно открыть в «Настройки → Лаунчер → Сообщить о проблеме». Открытие, предпросмотр и сохранение копии не отправляют данные. Пользователь выбирает приложения и создание Discord-тикета, проверяет подготовленный состав и отдельно нажимает «Отправить на сайт». Для отправки нужен профиль SEFI; сохранение JSON-копии работает без входа.

Лаунчер берёт только ограниченные записи запуска и фиксированные пути logs/latest.log и crash-reports/crash-*.txt. Чтение за пределами папки игры не допускается. После перезапуска доступны помеченные файлы прошлой сессии за сутки; они не выбираются автоматически. Известные данные авторизации, личные пути и распознанный чат фильтруются до предпросмотра. Политику и её тексты установщика обновляем вместе с этой функцией.

Приём использует существующий /api/public/community/client-report. Доставка в Discord идёт через очередь тикетов; при недоступности тикета интерфейс отдельно сообщает об успешном сохранении на сайте. Приватный просмотр по ссылке из тикета требует прав панели. Серверные файлы просмотра выкладываются отдельно, в согласованном общем релизе. Проверки: scripts/test-launch-reports.cjs и scripts/test-launch-reports-ui.cjs.
