# Серверная часть SEFI Skins

2026-10-08: бэкенд скинов развёрнут; pz-web active; Minecraft не перезапускался; лаунчер не опубликован. Резервная копия: /opt/pzserver/backups/community-skins-20261008-145517.

Ниже сохранена инструкция установки и устройства API.

Для будущего обновления панели: положить community_skins.py в web/, применить
api-skins.patch к web/api.py (или перенести ровно новый блок маршрутов),
положить test_community_skins.py в deploy/ и выполнить тест рядом с
существующим test_community_security.py. Перед обновлением сохранить резервную копию
community_users.db и проверить изменения относительно актуального API панели.

Данные хранятся в отдельной таблице community_skins существующей SQLite базы,
не в публичной папке. Таблица создаётся при первом обращении. Сброс удаляет запись.
Ник и права проверяются по актуальному профилю под ACCESS_LOCK, загрузка не позволяет
назначить владельца/UUID/ник из запроса. Переход на Microsoft сразу закрывает выдачу
старого скина; при получении официальной текстуры Minecraft клиент отдаёт ей приоритет.
Поддерживаются PNG 64×64, 8-bit RGB/RGBA, без чересстрочной развёртки, до 64 КБ.
Лаунчер нормализует выбранный PNG; сервер проверяет CRC, размер распакованных данных,
фильтры, удаляет метаданные и отвергает анимацию.

GET/POST /api/public/community/skin — собственный скин, X-Community-Token.
POST: {"png":"<base64 PNG>","model":"classic|slim"} или {"reset":true}.
GET /api/public/community/skins/<offline UUID>?name=<ник> — публичные пиксели,
модель и SHA256 без данных аккаунта. Несовпадающий UUID/лицензия/бан дают skin:null.

Клиентский мод ставится при каждом запуске игры для обоих типов аккаунтов.
Обновления загружаются асинхронно раз в 45 секунд, при ошибке — повтор через 10 секунд.
Пока сервис не развёрнут, загрузка в лаунчере показывает понятное сообщение,
а Minecraft сохраняет стандартные/официальные скины и продолжает запуск.
Для общей видимости всем игрокам нужен обновлённый лаунчер.

Изолированная проверка: для dev-лаунчера переменная SEFI_SKINS_API может указывать
только http://127.0.0.1:<port> или http://localhost:<port>. Упакованная версия
всегда использует https://mc.sotocoming.ru. Продовые токены при тестировании не нужны.
