# Проверки отказоустойчивости SEFI Launcher

Microsoft-сессия обновляется в основном процессе Electron, без окна авторизации.
Срок берётся из ответа Minecraft Services, а не из предположения о 24 часах.
Продление начинается, когда остаётся менее 30 минут. Перед созданием игрового
процесса дополнительно проверяется профиль; отозванный токен продлевается один раз.
Продление включает Microsoft, Xbox, XSTS и Minecraft Services: фиксированные
0,2 секунды не гарантируются. Запросы имеют ограниченный срок и число повторов.

Новый ключ продления сохраняется до запросов Xbox и Minecraft, чтобы последующий
сбой этих сервисов не потерял обновлённый ключ. На диске ключ защищён Electron
safeStorage / Windows DPAPI, включая резервную копию. Ключ продления и игровые
токены не возвращаются интерфейсу. При временной недоступности расшифровки
зашифрованное значение сохраняется без изменений. При отзыве Microsoft-сессии
нужен повторный вход. Для аккаунтов, созданных старой версией без ключа продления,
может потребоваться один повторный вход после истечения игрового токена.

Запись аккаунтов выполняется последовательно и атомарно, с синхронизацией файла
перед заменой. Повреждённый основной файл восстанавливается из последней валидной
копии. Если обе копии повреждены, ошибка видна пользователю и файлы не заменяются
пустым списком. Параллельные входы, выбор профиля и обновления не перезаписывают
изменения остальных аккаунтов. Продление удалённого профиля его не восстанавливает.

Неизменившиеся служебные моды не заменяются. EPERM/EACCES/EBUSY при замене файлов
повторяются ограниченное число раз; постоянная блокировка оставляет прежний файл
и предлагает закрыть Minecraft и проверить доступ. Изменения пользовательских
серверов и игровых настроек сохраняют остальные данные. Повреждённый профиль
Fabric загружается заново с проверкой версии и атомарной записью.

Последняя валидная конфигурация сборки кешируется для временных сбоев сайта.
Проверки авторизации и прав доступа по этому кешу не выполняются. Локальные
аккаунты и настройки появляются в интерфейсе без ожидания сетевых запросов.
Java SEFI остаётся личной Java 21 для клиента; установщики Java не принимаются
за bin/java.exe. Ошибки запуска Java и ненулевой код завершения игры показываются
с ограниченным журналом, из которого удаляются аргументы с игровыми ключами.

Серверный патч объединяет одноразовый запрос и билет автовхода в одну транзакцию
SQLite. Ошибка записи откатывает обе записи; повторная выдача успешного билета
запрещена. Ошибка базы классифицируется как недоступность сервиса. SEFI Community
не имеет суточного TTL в текущем коде. Сайт больше не удаляет сохранённый ключ
при ответах 5xx/429: выход происходит при подтверждённом 401.

Проверки лаунчера: `node scripts/test-resilience.cjs`.
Серверные проверки используют временные базы, вымышленных пользователей и
подменённые внешние сервисы. Настоящий вход Microsoft требует проверки игроком.
