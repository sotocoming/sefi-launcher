# SEFI Launcher: дизайн-система

База: ba91b2c, отдельный worktree, React/Tailwind/Framer Motion/Lucide.

## Аудит
Главная прячет адреса в 8–10 px; статусы конкурируют с неоном и маскотом. Все поверхности стеклянные, вложенные карточки усиливают шум. Часть кликабельных div недоступна с клавиатуры. Кнопки окна без доступных имён. Пинг ~35 ms вымышленный. Нет общей поддержки reduced motion. Шрифт зависит от Google Fonts.

## Направление
Вечер в игровом мире: сохранить игровой пейзаж и логотип; спокойная оболочка, крупное имя сервера, один главный запуск. Из рекомендаций ui-ux-pro-max приняты контраст, фокус, семантика и иерархия; отклонены 3D, неон и маркетинговые повторяющиеся CTA как неподходящие настольному лаунчеру.

Палитра: canvas #101116, surface #191B23, border #343744, text #F1F0F5, secondary #B2B4C3, accent #C4B5FD. Успех/ошибка/ожидание — отдельные смысловые цвета + текст.
Типографика: Segoe UI Variable / Segoe UI; заголовки 28–48, основной 14, подписи 12; табличные цифры для показателей. Локальный системный шрифт с кириллицей.
Ритм: 4/8/12/16/24/32. Радиусы: 8 контролы, 12 панели, 16 диалоги. Фокус 2px accent, отступ 3px.

Композиция (всё по левому краю):
[ навигация ][ имя сервера на существующем пейзаже            ]
[           ][ подключение / адреса       ][ сборка           ]
[ профиль   ][ новости                                      ]
[ версия    ][ запуск                                       ]

Настройки: секции с разделителями; новости: редакционные строки с изображением; аккаунты: смысловая пара Community/Minecraft; карта: максимум места карте. На узких окнах навигация компактнее, блоки складываются, прокрутка сохраняет доступ к действиям.
Motion: 160 ms отклик, 180 ms смена страницы, без бесконечного пульса/свечения; MotionConfig reducedMotion=user плюс CSS. Результат действия не зависит от анимации.

Проверка перед реализацией: акцент сохранён из SEFI, пейзаж — из проекта; выразительность сосредоточена в главном экране. Нет новых декоративных панелей или выдуманных показателей.
