# SEFI Launcher

Лаунчер Minecraft Java для сообщества SEFI и сервера Homestead Cozy.

## Возможности

- Вход в SEFI Community через сайт в системном браузере.
- Вход Microsoft и подтверждённая привязка Minecraft Java к профилю сообщества.
- Автоматический вход стандартного профиля SEFI с проверкой конкретного игрового подключения.
- Установка сборки, новости, карта и состояние сервера.
- Реакции на новости для авторизованных пользователей сообщества.

Готовый установщик Windows: [последний релиз](https://github.com/sotocoming/sefi-launcher/releases/latest).
Установщик пока не подписан цифровой подписью.

## Установка и восстановление сборки

Лаунчер сохраняет оригинальные имена файлов CurseForge. Моды устанавливаются в `mods`,
ресурс-паки — в `resourcepacks`, шейдеры — в `shaderpacks`. Загрузки проверяются на
целостность ZIP/JAR и записываются через временные файлы. Для повторной проверки
сохраняются размеры и SHA256; уже проверенные загрузки используются из локального кэша.
Если в конфигурации задан SHA256 архива сборки, он также проверяется перед установкой.
Локальные контрольные суммы и CRC не являются антивирусной проверкой или подписью автора.

Неполная установка не считается готовой и блокирует запуск. При обновлении со старого
лаунчера выполняется автоматическая проверка и восстановление; файлы `mod-ID-ID.jar`
переносятся из `mods` в `sefi-backups`. Пользовательские моды с другими именами остаются,
а существующие `options.txt` и список серверов сохраняются.

Настройка «Скрывать лаунчер на время игры» скрывает окно после запуска Minecraft и
возвращает его после выхода. Процесс лаунчера остаётся работать для автовхода SEFI.

## Разработка

Требуется Node.js 20 и npm. Из корня репозитория:

```sh
npm ci
npm run dev
```

Проверка и сборка приложения:

```sh
npm run build
npm run package -- --publish never
```

Windows CI запускается вручную во вкладке Actions и сохраняет установщик как артефакт.
Проверенные релизы публикуются отдельно, чтобы CI не создавал повторные черновики.

## Мод авторизации

Исходники Fabric 1.20.1 находятся в `mod_build`, готовый клиентский мод — в `resources/mods`.
Для пересборки мода нужны Java 17 и Gradle 8.12.1:

```sh
cd mod_build
gradle build
```

Лаунчер и клиентский мод не содержат серверных ключей. Развёртывание собственного сервера
требует отдельного бэкенда, EasyAuth и закрытой серверной конфигурации; одного клиентского
мода для автовхода недостаточно. Обычные сторонние лаунчеры поддерживаются сервером через
персональный игровой пароль либо подтверждённую Microsoft-сессию.

## Скины SEFI

В «Аккаунтах» появился блок внешнего вида активного профиля: выбор PNG 64×64,
3D-предпросмотр с вращением мышью или стрелками, масштабирование колесом, возврат
ракурса, обычная/тонкая модель, сохранение, отмена и сброс. Голова в боковой карточке
загружается из сохранённого скина вместе со вторым слоем и обновляется автоматически.
Общие скины доступны стандартным профилям SEFI Community. Для Microsoft и профилей
с привязанной лицензией показывается ссылка на официальный кабинет Minecraft.

Клиентский Fabric-мод `resources/mods/sefi-skins-1.0.0.jar` устанавливается для обоих
типов аккаунтов. Он асинхронно получает скины по offline UUID + серверному нику,
обновляет их раз в 45 секунд и отдаёт приоритет официальным UUID/текстурам.
Сервер повторно проверяет владельца, лицензию и доступ при каждой выдаче.

Подготовленный серверный патч и инструкция: [server_skin_patch](server_skin_patch/README.md).
Серверный патч развёрнут 2026-10-08; обновлённый лаунчер ещё не опубликован.
При недоступности API лаунчер объясняет недоступность сохранения,
а игра продолжает использовать обычные и официальные скины. Общая видимость требует
обновлённого лаунчера у всех участников.

Исходники мода: `skin_build` (Java 17+, Gradle 8.12.1). `gradle build` включает
проверку защиты Microsoft UUID и официальных текстур.

Дополнительные локальные проверки:

```sh
npx tsc --noEmit
node scripts/test-skins.cjs
node scripts/test-skin-mod.cjs
node scripts/test-skins-ui.cjs
node scripts/test-skins-packaged.cjs
```

Последняя проверка интерфейса использует Playwright из локального Codex runtime и
установленный Edge; её пути можно изменить под свою среду. Проверки API в панели:
`python panel/deploy/test_community_skins.py`.
